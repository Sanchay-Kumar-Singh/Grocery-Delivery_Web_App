<h1>Grocery Web App
</h1>
A modern grocery web application built with ReactJS and TailwindCSS, designed to provide a smooth and interactive shopping experience. The app uses mock APIs and custom authentication to simulate real-world functionality.

<h1>🛠 Features</h1>

User Authentication: Sign up and log in with custom authentication.

Product Listings: Browse groceries with a clean, responsive interface.

Mock APIs: Fetch product data dynamically using mock API endpoints.

Responsive Design: Optimized for desktop, tablet, and mobile screens.

Modern UI: Built with TailwindCSS for a sleek and consistent design.

ReactJS: Efficient state management and dynamic rendering.

<h1>🧩 Technologies Used
</h1>
ReactJS – Frontend library for building interactive UIs.

TailwindCSS – Utility-first CSS framework for responsive styling.

JavaScript (ES6) – Dynamic functionality and interactivity.

Mock APIs – Simulated backend for product data and authentication
